## Context

SIGES is the **Indicator and Goal Management System** developed as a Computer Engineering thesis project for the University of Holguín, Oscar Lucero Moya campus.

The project originated from the need to digitize and centralize the institutional management of indicators and goals, a process that depended on documents, spreadsheets, and manual calculations.

## The Problem

Manual management made it difficult to centralize information, track goals, and carry out evaluations in a timely manner.

## The Solution

SIGES centralizes the management of:

- Indicators.
- Goals and actual results.
- University processes.
- Areas and municipalities.
- Strategic objectives.
- Users and roles.
- Institutional evaluations and summaries.

The system incorporates rules to automate indicator performance evaluation and support decision-making.

## My Contribution

As the project's author, I participated in problem analysis, solution design, web application implementation, and integration of the modules required to manage and evaluate institutional indicators.

## Technology Stack

- C#
- .NET 10
- ASP.NET Core
- Blazor Server
- Entity Framework Core
- SQL Server
- FluentUI Blazor
- REST APIs

## Scope

The thesis documents 50 functional requirements, 42 REST operations, and four main roles within the system.

## Why It Is Relevant to My Professional Profile

SIGES is not an isolated CRUD project. It is a management solution with business rules, different user responsibilities, data persistence, APIs, and a web interface designed for a real institutional context.

This project represents my practical experience developing business applications with technologies from the .NET ecosystem.
