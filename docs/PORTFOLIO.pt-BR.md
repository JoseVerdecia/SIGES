## Contexto

SIGES é o **Sistema de Gestão de Indicadores e Metas**, desenvolvido como projeto de Trabalho de Conclusão de Curso em Engenharia Informática para a Universidade de Holguín, sede Oscar Lucero Moya.

O projeto surgiu da necessidade de informatizar e centralizar a gestão institucional de indicadores e metas, um processo que dependia de documentos, planilhas e cálculos manuais.

## O Problema

A gestão manual dificultava a centralização das informações, o acompanhamento das metas e a realização das avaliações em tempo hábil.

## A Solução

O SIGES centraliza a gestão de:

- Indicadores.
- Metas e resultados reais.
- Processos universitários.
- Áreas e municípios.
- Objetivos estratégicos.
- Usuários e funções.
- Avaliações e resumos institucionais.

O sistema incorpora regras para automatizar a avaliação do cumprimento dos indicadores e apoiar a tomada de decisões.

## Minha Contribuição

Como autor do projeto, participei da análise do problema, do desenho da solução, da implementação da aplicação web e da integração dos módulos necessários para a gestão e avaliação dos indicadores institucionais.

## Stack Tecnológico

- C#
- .NET 10
- ASP.NET Core
- Blazor Server
- Entity Framework Core
- SQL Server
- FluentUI Blazor
- APIs REST

## Escopo

O trabalho documenta 50 requisitos funcionais, 42 operações REST e quatro funções principais dentro do sistema.

## Por Que É Relevante para o Meu Perfil Profissional

O SIGES não é um projeto CRUD isolado. É uma solução de gestão com regras de negócio, diferentes responsabilidades de usuários, persistência de dados, APIs e uma interface web voltada para um contexto institucional real.

Este projeto representa minha experiência prática no desenvolvimento de aplicações empresariais utilizando tecnologias do ecossistema .NET.
