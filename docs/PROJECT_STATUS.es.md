## Proyecto académico en mantenimiento y mejora

SIGES fue desarrollado originalmente como proyecto de tesis para la carrera de Ingeniería Informática. Actualmente, el repositorio se encuentra en proceso de revisión y mejora como parte de su modernización y preparación para su uso como portfolio profesional.

Algunas funcionalidades pueden requerir correcciones, refactorización o actualizaciones antes de considerar el sistema preparado para un entorno de producción.

## Áreas actuales de mejora

- Corrección de errores y mejoras de estabilidad.
- Revisión y modernización de la base de código.
- Actualización de dependencias y paquetes.
- Mejora de la documentación.
- Ampliación de la cobertura de pruebas automatizadas.
- Mejoras de interfaz y experiencia de usuario.
- Configuración de despliegue y producción.

El objetivo de este trabajo continuo es preservar el proyecto académico original mientras se mejora progresivamente su calidad, mantenibilidad y preparación como proyecto de portfolio profesional.
