## Título do Projeto
**SIGES — Sistema de Gestão de Indicadores e Metas**

## Descrição para a Seção Projetos

Desenvolvi o SIGES como meu projeto de Trabalho de Conclusão de Curso em Engenharia Informática na Universidade de Holguín, Faculdade de Informática e Matemática, sede Oscar Lucero Moya.

O SIGES é uma aplicação web voltada para informatizar e centralizar a gestão de indicadores e metas institucionais. O sistema permite gerenciar indicadores, processos, áreas e objetivos estratégicos; registrar resultados reais; definir metas; aplicar avaliações automatizadas e consolidar informações para apoiar a tomada de decisões.

O projeto me permitiu trabalhar com C#, .NET, Blazor Server, ASP.NET Core, Entity Framework Core, SQL Server e FluentUI Blazor, além do desenho de regras de negócio, gestão de funções e operações REST.

## Versão Curta para Destaques

Projeto de conclusão de curso em Engenharia Informática desenvolvido para a Universidade de Holguín. Aplicação web em .NET e Blazor para gerenciar indicadores, metas, processos, áreas e objetivos estratégicos, automatizando a avaliação do desempenho institucional.

## Posicionamento Profissional

Ao apresentar este projeto, o foco deve estar no problema resolvido e nas decisões técnicas aplicadas, e não apenas no fato de ter sido um trabalho acadêmico.

**Problema:** informações e avaliações distribuídas entre documentos e planilhas.

**Solução:** uma plataforma web centralizada para gerenciar o ciclo de indicadores e metas, com funções, resultados e avaliação automatizada.

**Resultado:** uma solução de software voltada para um cenário institucional real.
