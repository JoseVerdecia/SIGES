## Projeto acadêmico em manutenção e evolução

O SIGES foi desenvolvido originalmente como projeto de conclusão do curso de Engenharia Informática. Atualmente, o repositório está passando por revisão e melhorias como parte de sua modernização e preparação para uso como portfólio profissional.

Algumas funcionalidades podem exigir correções, refatoração ou atualizações antes de o sistema ser considerado pronto para um ambiente de produção.

## Áreas atuais de melhoria

- Correção de bugs e melhorias de estabilidade.
- Revisão e modernização da base de código.
- Atualização de dependências e pacotes.
- Melhoria da documentação.
- Ampliação da cobertura de testes automatizados.
- Melhorias de interface e experiência do usuário.
- Configuração de deploy e produção.

O objetivo deste trabalho contínuo é preservar o projeto acadêmico original enquanto sua qualidade, manutenção e preparação como projeto de portfólio profissional são melhoradas progressivamente.
