## Academic Project Under Maintenance and Improvement

SIGES was originally developed as a Computer Engineering thesis project. The repository is currently being reviewed and improved as part of its modernization and preparation for professional portfolio use.

Some features may require bug fixes, refactoring, or updates before the system can be considered production-ready.

## Current Improvement Areas

- Bug fixes and stability improvements.
- Codebase review and modernization.
- Dependency and package updates.
- Documentation improvements.
- Increased automated test coverage.
- UI and UX improvements.
- Deployment and production configuration.

The purpose of this ongoing work is to preserve the original academic project while progressively improving its quality, maintainability, and readiness as a professional portfolio project.
