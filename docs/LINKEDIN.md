# SIGES en LinkedIn

## Título del proyecto
**SIGES — Sistema de Gestión de Indicadores y Metas**

## Descripción para la sección Proyectos
Desarrollé SIGES como mi Trabajo de Diploma para la carrera de Ingeniería Informática en la Universidad de Holguín, Facultad de Informática y Matemática, sede Oscar Lucero Moya.

SIGES es una aplicación web orientada a digitalizar y centralizar la gestión de indicadores y metas institucionales. El sistema permite gestionar indicadores, procesos, áreas y objetivos estratégicos; registrar resultados reales; definir metas; aplicar evaluaciones automatizadas y consolidar información para apoyar la toma de decisiones.

El proyecto me permitió trabajar con C#, .NET, Blazor Server, ASP.NET Core, Entity Framework Core, SQL Server y FluentUI Blazor, además del diseño de reglas de negocio, gestión de roles y operaciones REST.

## Versión corta para Featured

## Enfoque profesional
Al presentar este proyecto, el foco debe estar en el problema resuelto y en las decisiones técnicas aplicadas, no únicamente en que fue una tesis académica.

**Problema:** información y evaluaciones distribuidas entre documentos y hojas de cálculo.

**Solución:** una plataforma web centralizada para gestionar el ciclo de indicadores y metas, con roles, resultados y evaluación automatizada.

**Resultado:** una solución de software orientada a un escenario institucional real.
