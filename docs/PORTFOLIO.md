# SIGES como proyecto de portfolio

## Contexto

SIGES es el **Sistema para la Gestión de los Indicadores y Metas** desarrollado como proyecto de tesis de Ingeniería Informática para la Universidad de Holguín, sede Oscar Lucero Moya.

El proyecto surge de la necesidad de informatizar y centralizar la gestión institucional de indicadores y metas, un proceso que dependía de documentos, hojas de cálculo y cálculos manuales.

## El problema

La gestión manual dificultaba la centralización de la información, el seguimiento de las metas y la realización oportuna de las evaluaciones.

## La solución

SIGES centraliza la gestión de:

- Indicadores.
- Metas y resultados reales.
- Procesos universitarios.
- Áreas y municipios.
- Objetivos estratégicos.
- Usuarios y roles.
- Evaluaciones y resúmenes institucionales.

El sistema incorpora reglas para automatizar la evaluación del cumplimiento de indicadores y apoyar la toma de decisiones.

## Mi contribución

Como autor del proyecto, participé en el análisis del problema, el diseño de la solución, la implementación de la aplicación web y la integración de los módulos necesarios para la gestión y evaluación de indicadores institucionales.

## Stack tecnológico

- C#
- .NET 10
- ASP.NET Core
- Blazor Server
- Entity Framework Core
- SQL Server
- FluentUI Blazor
- REST APIs

## Alcance

El trabajo documenta 50 requisitos funcionales, 42 operaciones REST y cuatro roles principales dentro del sistema.

## Por qué es relevante para mi perfil profesional

SIGES no es un proyecto CRUD aislado. Es una solución de gestión con reglas de negocio, diferentes responsabilidades de usuario, persistencia de datos, APIs y una interfaz web orientada a un contexto institucional real.

Este proyecto representa mi experiencia práctica desarrollando aplicaciones empresariales con tecnologías del ecosistema .NET.
